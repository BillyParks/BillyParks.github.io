# Smooth Jazz Radio Studio

Smooth Jazz Radio Studio is a private tool that runs the 24/7 live streams on the [Smooth Jazz Radio](https://www.youtube.com/@SmoothJazzRadioLive) YouTube channel. It is used only by the channel's owner, on the owner's own computer, for the owner's own channel.

It uses the YouTube Data API to:

- create, schedule, start and end the channel's live streams;
- set each stream's title, description, privacy and cover image;
- post the channel's own welcome messages in its live chat.

It is not a public service, and nobody else can sign in to it.
