# Privacy Policy

*Last updated: November 15, 2026*

Smooth Jazz Radio Studio ("the app") is a private tool used only by the owner of the Smooth Jazz Radio YouTube channel to manage that channel's live streams.

## What the app accesses
The app signs in to one Google account, the channel owner's, with the YouTube scope `youtube.force-ssl`. It uses that access only to:

- confirm it is signed in to the Smooth Jazz Radio channel;
- create, update, start and end that channel's live broadcasts and streams;
- set the cover image of those broadcasts;
- post the channel's own messages in its live chat.

The app does not read viewers' chat messages, comments, subscriber lists or any other viewer information.

## What the app stores
The sign-in token is stored only on the channel owner's computer. It is never uploaded, shared or sold. The app collects no personal data from anyone, uses no analytics or advertising, and shares nothing with third parties.

## Google API Services
The app's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including its Limited Use requirements. The app also uses YouTube API Services, so the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy) apply.

## Removing access
The owner can remove the app's access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions) and by deleting the stored token.
